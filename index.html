    MIDI connection

    Plug in your USB-to-MIDI cable, connect its MIDI OUT plug to the DT25 MIDI IN, then choose the interface below. The DT25 listens on MIDI channel 1.

    Presets

    The DT25 has no program changes, so presets live in this browser. Loading one sends every setting to the amp.

      Profile

      Your profile is everything this app keeps in this browser: all presets, your current unsaved tweaks and your settings (MIDI channel, message spacing, DT50 options, Info mode). Save it as a file to back it up, or load it on another phone or computer.

      Loading a profile replaces the presets and settings in this browser. Save your current profile first if you want to keep it. The chosen MIDI interface stays as it is, since it differs per device.
